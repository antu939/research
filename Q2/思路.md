# 问题二：首轮随机供应链实验设计

## 1. 控制参数

### 第一层：背景尺寸参数

这些参数决定网络的基本规模和形态。

| 参数 | 含义 |
|---|---|
| \(N\) | 网络规模，主要指生产工艺节点 \(P\) 的数量 |
| \(D\) | 供应链深度，即最终产品到最上游之间的生产层数 |
| \(\psi(d)\) | 各层节点数量分布，控制 Pyramid / Barrel / Hourglass / Uniform 等层宽形状 |
| \(K_{in}\) | 一个生产工艺平均需要多少种上游投入，控制 assembly fan-in |
| \(K_{out}\) | 一个中间组件平均被多少个下游工艺共同使用，控制 downstream reuse / fan-out |

记为：

\[
\theta_{\mathrm{background}}
=
(
N,\,
D,\,
\psi(d),\,
K_{in},\,
K_{out}
)
\]

---

### 第二层：重点结构参数

这些参数决定同样规模的供应链具体形成什么样的连接结构。

| 参数 | 含义 |
|---|---|
| \(\phi_{\text{multi}}\) | Active multi-sourcing 程度：有多大比例的组件在正常状态下本来就由多个供应商同时生产 |
| \(\omega_U\) | 多源路线的 upstream overlap：多个供应商是否共享同一个上游依赖；越高代表路线越不独立 |
| \(\omega_C\) | Cross-branch commonality：不同组件分支是否复用共同的上游组件或工艺 |
| \(g_{\text{geo}}\) | 地理聚集倾向：供应关系更偏向全球分散还是区域集中 |
| \(\beta_H\) | Hub formation / attachment bias：已有大供应节点是否更容易继续获得新的下游连接 |
| \(\mu_M\) | Module / community affinity：连接是否更倾向留在同一个生产模块内部 |

记为：

\[
\theta_{\mathrm{core}}
=
(
\phi_{\text{multi}},\,
\omega_U,\,
\omega_C,\,
g_{\text{geo}},\,
\beta_H,\,
\mu_M
)
\]

因此第一阶段的网络生成参数为：

\[
\boxed{
\theta_{\mathrm{topology}}
=
(
N,\,
D,\,
\psi(d),\,
K_{in},\,
K_{out},\,
\phi_{\text{multi}},\,
\omega_U,\,
\omega_C,\,
g_{\text{geo}},\,
\beta_H,\,
\mu_M
)
}
\]

库存、capacity slack、生产 delay、运输 delay、采购份额等第一阶段先固定为统一规则，不作为首轮网络大类划分参数。

---

# 2. 首个实验逻辑

## 2.1 定义一个供应链大类

选择一组参数：

\[
\theta_k
\]

它定义一个供应链大类。

例如：

\[
\theta_1
=
(
N=500,\,
D=10,\,
\text{Barrel},\,
K_{in}=3,\,
K_{out}=2,\,
\phi_{\text{multi}}=0.7,\,
\omega_U=0.2,\,
\omega_C=0.3,\,
g_{\text{geo}}=0.4,\,
\beta_H=0.5,\,
\mu_M=0.8
)
\]

---

## 2.2 每个大类生成 500 张随机网络

对同一个参数点：

\[
\theta_k
\]

随机生成：

\[
\boxed{
G_{k,1},G_{k,2},\ldots,G_{k,500}
}
\]

这 500 张网络属于同一个大类，但具体拓扑随机不同。

---

## 2.3 对同一大类下的 500 张网络施加同一个 shock

首轮建议采用：

\[
\boxed{
\text{单个生产工艺 }P_i\text{ 完全停产 10 天，然后恢复}
}
\]

即：

\[
\bar c_i(t)=
\begin{cases}
0,&t_0\le t<t_0+10\\
\bar c_i^0,&t\ge t_0+10
\end{cases}
\]

每张网络都按照同一规则选择 shock 位置，例如从相对深度：

\[
\frac{d(P_i)}{D}\in[0.4,0.6]
\]

的生产节点中随机选择一个。

---

## 2.4 记录传播和系统响应

每次实验保存完整动态 trajectory，并至少计算：

### 传播指标

- Impact arrival time
- Cascade fraction
- Causal reach
- Maximum propagation depth
- Node-level peak effect
- Node-level cumulative effect

### 系统表现指标

- Final output peak loss
- Total output loss
- Time to first final impact
- Time to recovery
- Shock 期间损失 \(L_{\text{during}}\)
- Shock 后残余损失 \(L_{\text{after}}\)
- Response fluctuation \(V\)

---

## 2.5 改变网络大类

重复选择：

\[
\theta_1,\theta_2,\ldots,\theta_K
\]

每个参数点都生成：

\[
500
\]

张随机网络，并施加同一种 shock。

最终研究：

\[
\boxed{
\theta
\longrightarrow
\text{propagation / loss / fluctuation / recovery}
}
\]

是否存在稳定关系，例如：

\[
M=f(\theta)
\]

或者更低维的：

\[
\Lambda=g(\theta),
\qquad
M\approx F(\Lambda).
\]

---

# 3. 后续可替换的候选 shock

首轮只选一种 shock。后续可以在同一套网络上替换为其他标准局部干预：

1. **完全停产**
   \[
   \bar c_i\rightarrow0
   \]

2. **部分产能下降**
   \[
   \bar c_i\rightarrow(1-\rho)\bar c_i
   \]

3. **运输中断**
   某条运输 edge 暂时失效或运输 capacity 大幅下降

4. **运输 delay 激增**
   某条 edge 的运输时间突然增加

5. **区域性冲击**
   同一地理区域内多个 \(P\) 或运输 edge 同时受到影响

第一阶段默认采用：

\[
\boxed{
\text{single production node 100\% shutdown for 10 days}
}
\]

先研究：

\[
\boxed{
\text{同一种 shock 下，不同网络大类是否产生稳定的传播规律}
}
\]
